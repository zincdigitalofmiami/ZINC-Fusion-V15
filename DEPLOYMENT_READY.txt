⚠️  IMPORTANT REMINDERS

Security:
  • Generate STRONG random API key (32+ characters)
  • Use DIFFERENT keys for staging and production
  • Store keys securely (1Password, Vault, etc.)
  • NEVER commit keys to git
  • Rotate keys quarterly

Validation:
  • Test in staging BEFORE production
  • Verify performance improvement (<100ms)
  • Confirm auth is working (401 for invalid keys)
  • Check no tracebacks in error messages
  • Monitor logs for 30 minutes after deployment

Rollback:
  • Keep previous deployment URL ready
  • Document rollback procedure: vercel rollback <url>
  • Can remove FUSION_API_KEY to disable auth (emergency only)
