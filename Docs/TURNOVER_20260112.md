# PART 3: HUNTER ARCHITECTURE

## What a Hunter Does

**NOT:**
- A calculator that reports data
- A static prompt that runs daily
- "Let's give it instructions and turn it loose"

**IS:**
- An AI agent **trained for this exact purpose**
- Actively pursues anomalies and patterns
- Uses tools to investigate
- Learns from outcomes
- Gets smarter every week

## The 8-Step Behavior Loop

```
1. TRIGGER      → Anomaly detected in domain data
                  Example: "Crush margin at 1.8 percentile"

2. DECIDE       → What should I investigate?
                  Query pattern memory: "Have I seen this before?"

3. GATHER       → Use tools: Database, Scraper, News, Cross-Domain
                  Pull historical patterns from memory

4. CORRELATE    → What does this mean together?
                  Cross-domain alignment check

5. DISCOVER     → Output: Story + Prediction + Confidence
                  "Supply squeeze imminent - 4 weeks, 87% confidence"

6. LEARN        → Store pattern in memory
                  Tag with regime context
                  Update base rates when outcome known

7. GATHER MORE  → Find similar historical setups
                  Build pattern clusters
                  Strengthen cross-domain correlations

8. SANITY CHECK → Am I still grounded?
                  Does current regime match pattern regime?
                  Is sample size sufficient?
                  Am I ignoring contradicting signals?
                  IF DRIFT: Return to base, flag uncertainty
```

## Pattern Memory Bank

Every Hunter maintains learned patterns:

```

ANTI-CORRELATIONS:
  FED (hawkish_pivot): -15% accuracy when present
  PALM (cpo_collapse): -10% accuracy when present
```

## Regime Guardrails (Stay Sane)

| Guardrail | Implementation |
|-----------|----------------|
| Regime Tagging | Every pattern tagged with regime(s) it occurred in |
| Regime Matching | Only apply patterns matching current regime (±1 category) |
| Sample Size Floor | Confidence capped if occurrences < 10 |
| Contradiction Flagging | Must acknowledge opposing signals |
| Domain Boundary | Hunter cannot make claims outside its domain |
| Drift Detection | If reasoning strays, return to fundamentals |
| Confidence Calibration | Stated confidence must match historical accuracy |
| Human Escalation | Unusual patterns (< 3 occurrences) flagged for review |
